关于「小说版权是不是都免费」—— 答案：不是都免费

各平台的 IP 授权分成「免费授权（分成/保底）」和「付费购买」两类。七猫、书旗、阅文目前主要是「免费授权 + 分成/保底」；而番茄的规则已经变了——「番茄IP改编合作」（模式二）现在是邀约制、普通工作室签不了，拿不到 IP 库，只能向番茄小说单独付费购买改编权，或走「普通授权」只发自己的原创内容。详见 第①章。

💡
但别慌——免费拿 IP 的路没有断

番茄虽收紧，但 七猫（改编书单）、书旗（漫剧启航计划）、阅文（漫剧助手 10万+ IP） 依然对个人/工作室开放免费授权。而且你已签的「普通授权」合同，现在就能发原创漫剧变现。番茄 IP 不是唯一解。

Step 1 · IP Licensing

①小说版权怎么拿：免费授权 vs 付费购买

先搞清楚一个根本问题：不是所有平台都免费授权。现状分两种——「免费授权（分成/保底）」和「付费购买版权」。下面按平台逐个讲清楚。

一、各平台版权获取方式总览

平台授权方式要不要钱收益模式当前状态

番茄规则变动的真相（重要）

番茄的「番茄IP改编合作」（模式二）本质是平台邀约制——平台主动邀约优质团队才签得到，普通工作室看不到、签不了。之前需要「IP库开通申请表 + 样片 + 历史作品」审核。如果你现在签不了模式二、拿不到 IP 库，剩下的路是：①向番茄小说单独付费购买 IP 改编权；②走「普通授权」只做原创内容；③改用七猫/书旗/阅文的免费 IP。

Step 2 · DramaBuddy 漫剧助手

②阅文「漫剧助手」怎么用（含接单广场/试稿）

「漫剧助手」（DramaBuddy）是阅文集团推出的 AI 漫剧创作平台（aicomic.yuewen.com），整合了10万+ 部阅文正版网文 IP + AI 全流程创作工具 + 接单/试稿市场。这是你拿阅文 IP 和接单变现的核心平台。

一、注册与开通

1
手机号登录访问 aicomic.yuewen.com → 用手机号注册/登录
2
企业激活进入「企业激活」页面，输入激活码（企业机构需要，个人可能免激活）→ 点「去创建企业」
3
完善企业信息填写企业/工作室信息 → 完成存储设置 → 进入工作台

二、核心功能（创作链路）

📖 小说内容理解

一键拆书、问书、剧情理解，吃透千万字网文，快速把握故事主线、人物、爽点。

✍️ 剧本智能改编

针对小说任意章节，生成专业级「一卡」「全集」剧本，把网文转成漫剧剧本。

🎨 角色/设定智能提取

智能提取角色、场景设定，生成统一的角色资产，保证人物一致性。

🎬 分镜智能生成

分镜直出可用率 80%+，接入 Vidu Q3、Seedance 2.0 等 AI 视频模型，图/视频/配音多模态输出。

👥 团队协作

团队空间、成员权限划分、镜头级审核批注、素材共享——正好适配你 4 人工作室协作。

💰 收费模式

付费充值（点数制）。IP 授权本身是分成制，AI 工具按点数收费。

三、marketplace 三大功能：爆款剧本 / 接单广场 / 合作试稿

🔥 爆款剧本

平台精选的爆款剧本库，可直接浏览、挑选、购买/授权使用。适合没有好故事、想快速起量的阶段——直接买现成爆款剧本改编，省去从零创作的试错成本。

📋 接单广场（怎么接单）

平台/出品方发布改编订单（指定某部阅文 IP 改编成漫剧），创作者浏览订单、接单承制。接单流程：浏览订单 → 看要求（IP、题材、档期、预算）→ 提交接单申请/作品集 → 平台审核 → 通过后签约承制。核心：先有「作品 demo + 历史案例」，接单通过率才高。

✒️ 合作试稿（怎么过审核）

试稿 = 平台给你一个命题/IP，让你做一小段样片或剧本，通过审核后获得长期合作资格。过审要点：①严格按命题要求做（题材/规格/画风）；②画风统一、人物不漂移；③节奏紧凑、开头抓人（黄金三秒）；④按时交付。试稿通过后，就能进接单广场接单、享受平台 IP 资源。

📖
官方使用手册

阅文漫剧助手官方使用手册：docs.qq.com/doc/DTmxJdVJtYXpHUEhQ（腾讯文档）。接单广场、试稿的具体规则以平台页面和手册为准。

Step 3 · 七猫改编书单

③七猫：拿版权 → 改编 → 上架全流程

七猫是目前对工作室最友好的免费 IP 渠道——改编书单直接开放选书，改编成剧本就能拿保底（1.5–10 万）。下面是完整流程。

第一步：进改编书单选书

入口：zuozhe.qimao.com/front/screenplay/adapt-book-list（七猫作家专区 → 剧本改编书单）

筛选维度可选
改编方向动漫短剧（你选这个） / 真人短剧
所属频道女生小说 / 男生小说 / 短故事
作品分类现实/衍生言情/游戏竞技/幻想言情/古代言情/现代言情 等
作品字数30万以下 / 30-50万 / 50-100万 / 100-200万 / 200万以上
是否完结已完结 / 连载中
热门书单热门精选/潜力推荐/黑马来袭/人气打赏/口碑好书/人气互动

第二步：选书 + 改编

1
选书按题材、热度、字数筛选，挑热度高（几十万~百万热度）且契合漫剧爆款品类的书
2
阅读原著点每本书的「阅读原著去改编」按钮，读原著吃透故事
3
改编成剧本用七猫「剧本」创作功能（或 AI 工具），把小说改编成漫剧剧本
4
投稿签约提交剧本 → 平台审核 → 签约拿保底（短篇1.5-5万/中长篇3-10万）

第三步：授权后做漫剧 + 上架

🔗
拿到七猫授权后，怎么做成漫剧并上架？

七猫改编授权到手后，你有两条路：①在七猫体系内发——七猫漫剧（百度推出，安卓已上线）或七猫合作的发行渠道，走七猫的合制/分销（联系漫剧商务王女士 wangYF_1020）；②做成品发到抖音/红果——前提是七猫授权不排他、允许第三方渠道，然后走你已签的「普通授权」合同上传（版权信息里如实填七猫 IP、勾「非版权专区IP改编」）。签约时务必确认排他条款。
